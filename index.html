JUEGO INTERACTIVOGITHUB PAGES

CONTROL
DE TRÁFICO.

Un juego de gestión de tráfico en el que el jugador coordina los semáforos para mantener el flujo vehicular, evitar congestión y prevenir colisiones. El segundo nivel conecta dos intersecciones que deben controlarse por separado.

CÓMO ESTÁ HECHO

Se publica con GitHub Pages. Está construido con HTML, CSS y JavaScript: el código de script.js se ejecuta en el navegador y controla semáforos, vehículos, tiempo, puntuación y congestión. No usa una base de datos; la partida y la mejor puntuación se mantienen durante la sesión y pueden reiniciarse al recargar.

JUEGO MULTIJUGADORVERCEL + SUPABASE

CITY
CAOS.

Una ciudad compartida en la que varias personas pueden construir, decorar y modificar el mismo tablero de 12 × 12 casillas. Se pueden colocar edificios, carreteras y elementos naturales, además de usar herramientas para cambiar el mapa.

CÓMO ESTÁ HECHO

La aplicación se publica en Vercel. La lógica de app.js corre en el navegador y usa la API REST de Supabase: city_tiles guarda los objetos por sala y casilla, mientras city_presence registra quién está conectado. El mapa se consulta aproximadamente cada 800 ms y la lista de jugadores cada 3 segundos; la sincronización es periódica, no usa WebSockets.
